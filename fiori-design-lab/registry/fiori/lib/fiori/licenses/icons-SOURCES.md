# SAP-icons v5

`src/components/fiori/sap-icon.tsx` contains the unmodified SVG pathData and viewBox
from 45 icons in `@ui5/webcomponents-icons@2.28.0/dist/v5/`.

Source: https://github.com/UI5/webcomponents/tree/main/packages/icons
Copyright SAP SE and contributors. Apache-2.0, included in LICENSE.txt.

This static subset avoids importing UI5 icon registration or UI5 runtime code.
Every requested icon name exists in the official v5 collection; no aliases or
hand-drawn replacements were needed.

The Value Help phone Filters view adds the official `nav-back` path from
https://unpkg.com/@ui5/webcomponents-icons@2.28.0/dist/v5/nav-back.js.

The default Switch off state adds the official `less` path from
`@ui5/webcomponents-icons@2.28.0/dist/v5/less.js`.
